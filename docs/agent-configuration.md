# Agent 配置与文本修改

在 Agent Center 的跳房子中，点击正文下方的「＋」，选择「修改文本」，即可建立自己的正文润色、措辞检查或其他文本修改 Agent。新 Agent 默认停用，处理「显示的正文」、跟随当前模型，并使用自动调用方式。

「＋」只列出当前落点可以添加的项目，分为新建、已有和内建 Agent。已存在的唯一功能、容量已满或阶段不适合的选项会隐藏。新建的「修改文本」用于生成待确认的正文修改；「自定义提示词」独立执行任务，产物可供后续房子引用。右侧「＋」在同一行添加并行房子，上下「＋」新建一行；正文优化应放在正文生成之后。

## 配置与使用

1. 翻到卡片反面，确认配置范围，填写名称和「任务要求」。例如：保留情节、人物语气和信息，减少程式化对照、空泛评价与重复措辞，让叙述更自然。
2. 默认的「显示的正文」提取当前消息中可阅读的文字，排除思考过程、记忆表格、变量指令和摘要等内容。展开「查看本次正文」确认发送给 Agent 的正文及字数；编辑器默认折叠这份预览。需要精确规则时可选「按正文规则」、完整回复、起止标签或正则捕获组。
3. 默认「跟随当前模型」显示当前会话实际使用的模型，也可为 Agent 单独选择 API 配置。指定同一连接下的其他模型名称放在折叠项中。
4. 用独立总开关启用，再选择「自动 / 手动 / 自动＋手动」。上下文和自定义提示词区块按需展开；卡片侧边的细竖条打开实际请求预览，使用与发送相同的提示词组装逻辑。
5. 底部点击「保存」或「试运行」。有未保存修改时显示「保存并试运行」；自动模式同样支持这次明确点击的试运行，长期调用方式保持原设置。试运行使用当前目标回复，生成候选后点击「查看修改」，确认后才替换原文。
6. 添加或调整房子后保存流程。自动修改在回复完成后按流程位置执行，正文优化的房子放在正文之后。

保存、试运行和查看修改位于固定底栏，运行时可从同一处取消。正文预览支持刷新与选取原文；恢复配置、跨模式复制和删除收在「更多操作」中。保存过程中继续编辑会保留新草稿，未保存修改仍受离开确认保护。

回复完成后会生成修改候选，在 AC 点击「查看修改」进入差异预览，可选择片段并应用或忽略。正文在用户确认后更新。等待确认期间可以继续聊天，其他步骤读取已提交的正文。

单条回复的消息菜单提供「Agent 工具」，打开同一个工具箱并固定目标回复。可先选择回复中的文字，再调用修改工具；若渲染后的文字无法唯一定位，在工具配置中用「选取原文」选择精确范围。选区独立于保存的正文规则，支持 Windows 换行符。格式修复沿用最新完整回合的来源限制。

## 配置范围

| 模式 | 当前范围 | 默认范围 |
| --- | --- | --- |
| 创意写作 | 当前角色卡 | 所有角色卡 |
| 聊天 | 当前聊天 | 聊天全局设置 |

名称、启停、模型、任务要求、提示词区块、调用方式和处理内容作为整份配置保存。当前范围可以覆盖默认配置，显式停用也属于覆盖。「跟随全局配置」恢复继承；两种模式之间可显式复制，复制后初始停用。

跳房子的流程范围管理房子顺序和组合，卡片的配置范围管理 Agent 行为。从房子进入卡片时沿用流程当前选中的范围。删除 Agent 后，保存流程中对它的引用显示停用，可以移除房子。

输入建议与格式修复也使用同一个配置编辑器。输入建议继续沿用输入停顿、Tab 和触屏部分采纳；创意写作的格式修复启用前需填写格式要求，例如 `<tableEdit>` 的完整结构。

## 内建 Agent 的默认任务

文本建议与格式修复的「任务要求」直接显示实际使用的默认提示词，可以在原文上修改。「恢复默认任务」只恢复任务内容；模型、输出上限、格式要求和参考资料继续保留，点击保存后生效。首次查看默认内容属于只读操作；之前保存的自定义内容及作用范围继续有效。

「自动包含」列出内建任务的必要输入：文本建议使用光标前最近 2400 字符和光标后 600 字符；格式修复使用完整原始回复、当前场景适用的格式规则和本地解析结果。历史消息、世界书和固定提示词位于「附加参考资料」，默认关闭，可按需要选择。

「运行设置」显示可调整的最大输出 Tokens（文本建议默认 96，格式修复默认 6000）与内建采样温度（分别为 0.3、0）。修改格式修复的任务后，最小行补丁协议及原文校验仍生效。侧边细竖条可查看本次完整提示词、资料和请求参数；创意写作中具体要修复的格式仍由「格式要求」定义。

旧格式修复配置中的任务原本是附加指令，现在与默认任务一起显示；只修改模型等其他设置时保持原语义。明确编辑任务后，编辑框里的完整内容成为新的任务要求。

## 正文与修改保护

- 「显示的正文」复用消息的显示处理结果作为纯文字输入，再将修改映射回原始回复。思考、记忆、变量等隐藏内容和 HTML 外壳保留原文；参考上下文只提供背景。旧配置的正文规则和选区继续按原始回复的位置处理。
- 显示正文按当前角色卡、会话的显示正则提取。若自动任务尚未提取正文就切到另一聊天，本次任务会提示暂无显示正文，避免套用另一角色的规则；回到原聊天后可试运行。完整的交互 HTML 页面使用指定标签或「选取原文」定位正文。
- 静态 HTML 中存在通过 CSS 样式隐藏的内容、无法确认可见正文范围时，显示正文提取会停止并提示原因。改用指定标签或「选取原文」明确需要优化的内容后再运行。
- 单一原文文本节点可以增减段落；多个 HTML 文本节点之间的修改需保留可一一对应的段落结构。若显示文字重复、跨内联节点、被正则改写或显示顺序无法对应原文，界面会提示改用起止标签或「选取原文」，匹配明确后再处理。
- 匹配缺失、重复或歧义时提示原因；需要用户调整规则。选区超过 40000 字符时应缩小处理范围。
- 高级正则在独立 Worker 中执行，1 秒超时；系统能力不足时可改用起止标签。
- 模型提交修改片段，单次最多 20 个片段、200 行改动。思考块和表格、变量、生图等功能块保留原文。正文修改兼容模型在单一 JSON 外包裹完整代码围栏，仍严格校验版本、原文行和补丁范围；额外说明、混杂输出或不完整 JSON 会被拒绝。
- 应用前再次核对消息、分支、角色、存档与原文。旧候选过期后需重新运行；确认润色作为正文编辑处理，已有变量、记忆等指令保持原执行状态。
- 当前有效配置最多 8 个回复 Agent；任务状态和候选保留在内存中，最多 30 项。关闭应用后需要重新生成候选。

提示词模板库、分享和「等待确认后再继续流程」属于后续扩展。

## 输入 Agent 与调用方式

输入建议行右侧「＋」新建输入 Agent，默认停用、自动调用。选择独立模型，填写任务要求，设置结果形式后启用并保存。每个有效范围最多 8 个自定义输入 Agent，与回复修改 Agent 分别计数。

| 结果形式 | 展示与采纳 |
| --- | --- |
| 续写建议 | 在工具箱查看，采纳时插入光标处 |
| 修改草稿 | 支持所选草稿文字或整份草稿，复用差异确认，原生撤销可恢复 |
| 资料与建议 | 在工具箱独立查看和收起 |

自动输入任务在停顿约 900 ms 后运行；内置灰字续写保留原有调度、Tab／逐字和触屏拖选方式。所有输入自动任务共享每分钟 12 次预算，自定义输入任务最多同时执行 2 个。继续输入、输入法组合、切换会话或存档会取消或使旧结果过期；停止输入／窗口失焦暂停自动请求。每个自定义输入 Agent 只保留最近任务，内存候选最多 20 项，退出后清空。参考资料来自所选上下文和自定义提示词；自定义输入任务可显式选择下文的参考工具。共享预算按自动任务计数，开启工具后单个任务可能产生多次模型请求。

总开关和调用方式分开保存。关闭保留配置与房子位置，取消任务并撤下手动入口；重新启用保留原模式。手动房子保持颜色并标记「手动」，自动流程经过该位置时跳过。自动下游显式引用仅手动节点时，保存流程会提示调整引用。正文及内联融合成员保持各自能力，不开放无独立执行契约的手动模式。

旧版输入建议默认保留自动；旧回复 Agent 的自动设置迁移为自动＋手动，旧手动设置继续手动；读取期间不重写旧数据。

## 手动工具箱

点击输入框旁的「＋」，再选择工具箱，收集当前范围内已启用、允许手动调用的 Agent。有待查看结果时，「＋」显示提示点，展开后的工具箱按钮显示数量。工具箱打开后收起扩展按钮，保持靠近「＋」。默认处理当前草稿，可切换最近或较早回复；从消息菜单进入则锁定该消息。目标不适用时显示帮助，手机点击查看。

置顶、顺序及快捷键保存在本机 UI 偏好中。工具超过 6 个时提供搜索；快捷键自行设置，可在鼠标位置附近打开，面板随后保持固定。手机点按打开并适配可视区域。工具运行、取消及结果在列表内显示；自动输入任务的结果另列在同一个面板的「输入任务」中。

自动、手动和文本修改的试运行都使用保存后的配置。试运行要求 Agent 已启用，与长期手动调用资格分别校验。重复运行同一对象与版本会复用进度或待确认候选；应用前检查目标、会话、存档及总开关。调用方式控制后续任务资格；正在运行的任务仍可取消。草稿候选直接写回输入框，回复候选通过现有原文编辑入口提交。

实现分为 `agent-invocation.js`、`input-agent-runtime.js`、`input-agent-composer.js`、`agent-toolbox.js`；`agent-tools-app-runtime.js` 统一装配配置服务、候选生命周期和 UI，`app.js` 注入模型、存储及提交能力。

专项检查：`npm run test:agent-config`；Windows WebView 的隔离组件检查为 `dev-agent-tools-cdp-smoke.mjs`、`dev-agent-invocation-controls-cdp-smoke.mjs`、`dev-agent-configuration-cdp-smoke.mjs`。模型回复与配置均为隔离测试数据。


## 参考资料与处理对象

卡片将「处理内容」与「参考资料」分开配置。以正文优化为例，选择显示的正文作为处理对象，最近 3 轮对话帮助模型理解剧情；当前助手回复只出现在修改对象中，历史回复作为只读资料，确认修改仅作用于这一条回复。

- 最近对话：新 Agent 默认按轮，提供快捷数量、用户／AI 角色筛选，以及是否把目标所在轮算入窗口。按轮包含用户消息和对应 AI 回复；旧配置保留按消息计数，可以自行切换。选择历史回复时参考截止到该回复，后来的内容不参与。
- 世界书：可搜索选择整本或展开勾选条目。整本使用有效条目；选择整本会替换这本书的单条选择。来源首次展开及选中时加载，关闭时保留勾选；被删除或停用的来源会标记原因。条目引用使用已有只读合并逻辑，参考读取保留变量运行状态。
- 固定提示词：选择当前角色／会话有效预设内的具体区块。按真实启用状态与排序识别来源；固定正文作为参考文本发送，其中占位符保持原文，不额外运行预设或变量脚本。
- 「预览参考资料」展示实际发送的参考文字、来源与截取状态。默认参考预算 10000 字符，可在高级选项调整至 500–40000。保存来源 ID；之后世界书或预设更新会在下次构建时读取新内容。

历史参考内容沿用会话显示正则和正文提取，过滤思考、记忆表格、变量等功能内容；目标映射仍使用原有严格校验。上下文构建与模型请求绑定角色、聊天和存档，切换后中止旧请求。整本世界书之间如果引用了相同条目，显式选择多本时仍可能重复参考；预览可以查看具体内容。

## 工具与执行过程

自定义回复 Agent 和输入 Agent 可以在「可用工具」中启用工具并逐项勾选。候选来自 APP 已注册、经过检查的参考工具，包括世界书读取、会话及资料查询、修改预览和联网检索等。工具列表保持中文名称、搜索与标题帮助；联网工具依照选定模型的联网设置显示可用性。

每次只向模型提供勾选工具，并沿用 APP 权限控制。参考查询使用原生函数调用，工具结果作为参考送给模型，最后单独生成修改片段或文字结果。当前接入支持工具协议的连接；不支持的模型会显示具体原因。工具参考查询最多 1–8 轮（默认 4），总任务 120 秒、单工具 30 秒，最多执行 12 次工具。达到查询上限后生成最终结果。

回复 Agent 的结果可以选择「修改正文」或「资料与建议」。前者沿用差异确认，后者独立展示、复制及收起，适合剧情检查、事实核对等任务。工具箱的「回复任务」收集自动生成的资料结果；点击卡片可查看该 Agent 的详细执行过程。

运行卡按模型处理、工具查询、结果生成展示状态、输入与结果，详情默认折叠。「模型思考」只展示 API 实际返回的可见思考或摘要。执行记录保留在内存候选中，最多 32 步，长文本有界截取，关闭 APP 后清空；展开时才挂载长详情，流式更新节流至 120 ms。选项与折叠使用短时淡入／位移动画，尊重系统和 APP 减少动态效果设置。

这套工具入口目前处理参考查询。新增外部工具注册、执行写入动作及确认后继续的长流程，可以在现有权限和结果确认机制上扩展。

交互组织参考了 [Langflow Agents](https://docs.langflow.org/agents) 对输入、记忆和工具的区分，以及 [Flowise Agentflow V2](https://docs.flowiseai.com/using-flowise/agentflowv2) 的显式上下文与运行步骤呈现；实际执行沿用本 APP 的权限与修改确认。
