# 图片提示词

入口：聊天、创意写作的“生成图片”窗口，以及动态配图。提示词属于每次生成的图片；从历史图片重新编辑时恢复该图片的区块。

## 常用操作

- 顶部“正向提示词”直接粘贴完整提示词即可生成；下方是选填的“负向提示词”，再下方用“角色”旁的 `+` 按需添加角色。
- 正向、负向为固定输入区，没有添加区块、改名、启停或移除操作。模型未使用独立负向且内容为空时隐藏该输入区；已有负向保留并标记“当前模型未使用”。
- 有固定内容时，同一输入框内以虚线分开：前缀在本次输入上方，后缀在下方；固定负向在本次负向上方。固定分隔区可编辑或清空，修改只作为本次覆盖，随图片保存。没有固定内容时直接显示本次输入。
- 角色可改名、折叠、启停。复制和移除使用名称右侧的图标按钮；区块内有正向或角色负向提示词时，移除前弹出确认，也可撤销最近一次移除。
- 电脑拖动把手排序，手机长按把手拖动；键盘聚焦把手后可用上下方向键排序。角色标题右侧的 `+` 是唯一添加角色入口。
- 点击或拖动右侧细竖条打开发送预览；宽屏可展开完整预览，窄屏直接进入完整预览。点击来源标记返回相应区块。
- 直接编辑本次区块并生成，提示词随图片记录保存。切换模型保留已有区块，重新计算参与发送的内容。
- 区块标题使用文字，拖动把手放在右侧。输入区融入卡片，聚焦时柔和强调所在区块。

“图片生成参数”恢复固定正向前缀/后缀和适用渠道的固定负向编辑，说明放在标题悬停/点按帮助里。固定正向适用于各生图渠道，由 App 组装成最终提示词。该页面保存的是默认值；新建生成读取默认值，历史图片优先恢复自身快照。质量、尺寸、采样等也继续在此管理。

生图输入页保留预设页面的细竖条预览交互，没有提示词预设管理、手动保存、重命名预设或导入导出。

## 模型适配

| 模型能力 | 实际发送 |
| --- | --- |
| NovelAI V4 / V4.5 | 主画面、最多 6 个角色、各自负向及可选位置分别发送 |
| NovelAI V5 | 最多 22 个角色；沿用已接通的角色请求结构 |
| 普通文本生图 | 固定前缀、本次正向、角色描述、固定后缀组合为提示词；自然语言模型保留角色名称 |
| 支持独立负向 | 负向单独发送；按服务商、模型及 ComfyUI 工作流识别 |

停用区块、其他渠道的旧区块和当前模型未使用的负向保留在草稿中，列于预览的“本次未使用”。角色区块在普通模型中用于组织文字，区域定位由模型自身能力决定。

NovelAI 位置默认自动，可切换为自定义网格。角色数量超限或同时使用角色块与 `|` 分隔语法时，在发送前提示修正。字段依据：[官方多角色说明](https://docs.novelai.net/en/image/multiplecharacters/)、[官方 API 定义](https://image.novelai.net/docs/doc.json)。

## 旧数据与自动生成

新建生成从本次输入开始；固定前缀、后缀和负向按原服务商复制到本次编辑。清空固定内容也属于有效覆盖，提交和重开旧图时优先保留本次值。前一版独立提示词预设的用户数据保留在原处，生成流程已停止读取和应用。

旧图片的多个画面/风格/负向区块呈现在对应输入分区中；打开时保留完整原始快照、前后顺序、启停和服务商限定，只有实际编辑的同类同作用域文本才会合并。旧风格位于正向的前/后分隔区，停用及其他渠道内容继续保留于快照与预览。

自动生图继续接收 Agent 的 `<image_prompt>` 文本，填入本次画面并与固定区块组合。聊天、创作、动态与女仆共用请求编译入口。贴图制作沿用自己的完整提示词流程。

图片记录保存区块快照和组装结果；重新编辑/生成读取该快照，编辑副本与其他图片相互独立。旧图片只有文本时按旧记录中保存的前后缀和负向恢复。

## 代码与验证

- `ui/image-prompt/image-prompt-utils.js`：纯函数规范化、能力识别与编译。
- `ui/image-prompt/image-prompt-runtime.js`：按图片建立草稿及发送组装。
- `ui/image-prompt/image-prompt-form-utils.js`：把旧区块映射为固定输入区，并隔离本次编辑。
- `ui/image-prompt/image-prompt-editor.js`：共用分块编辑器与发送预览。
- `ui/chat-image-prompt-modal.js`：从 `app.js` 抽出的完整共享生图窗口。

Windows 专项：`npm run test:image-prompt`。开发窗口交互：`node scripts/tests/dev-image-prompt-cdp-smoke.mjs`。

已用模拟请求验证 NovelAI 字段及 OpenAI 最终提示词、质量和尺寸传递，并验证新建图片独立草稿和旧图恢复；已检查 Windows WebView 的鼠标和触屏模拟。真实服务商生图及 Android 真机手感仍需实际使用验收。

结构化 Agent 输出、角色卡自动绑定、外观模板库、更细的区域画布和参考图与角色绑定，属于后续阶段。
