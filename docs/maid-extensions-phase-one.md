# 女仆与 AC 扩展：首期交付

2026-09-25，基于 `6025359 / 0.7.4-preview`。范围依照工作区的《女仆扩展计划复核-2026-09-25》。

## 功能与入口

| 功能 | 入口及行为 |
|---|---|
| 女仆 Skill | 内置「生成并设置头像」「按资料编写世界书」。模型看到简短目录后，自行调用 `app.read_skill` 读取流程。引用功能仅在原候选预算内提升，不授予权限，也不替代现有工具说明。 |
| 自定义实时语音 | 连线配置 → 实时语音 → 自定义 → 高级设置。支持检测阈值、停顿等待和句首音频保留，保存、复制、重新加载时保留参数。 |
| 图片反应 | 消息反应选择器 → 自定义／添加图片；管理中可移除。PNG、WebP、JPEG 最大 8MB，等比放入 96×96，透明留白，压缩后不超过 30KiB，最多 60 张。 |
| 小管家 | AC → 小管家。选择独立模型并保存启用；新建未填写名称的存档在后台命名。可选当前聊天／角色或当前模式全局配置，默认关闭。 |
| 正文评分 | AC → 正文评分。选择独立模型并启用，填入文本或载入最近回复，手动开始评分。按换行分段，最多 40 段、12000 字符，单次批量请求；只展示结果，不写回正文。 |

VAD 默认值：阈值 `0.5`、静音 `600ms`、句首 `300ms`。范围分别为 `0–1`、`100–5000ms`、`0–5000ms`。仍使用现有自定义 Realtime 协议及音频格式，APP 保持回复轮次控制权。

## 存储与异步行为

- 反应素材使用内容摘要作为稳定 ID；消息仅保存引用、名称和参与者。体验包与完整自定义包只打包相关聊天使用的图片，导入按摘要校验、去重，并避开已有普通贴图包 ID。
- 反应素材不会加入普通贴图界面或模型贴图词表。取消导入不写入素材，未选择聊天也不导入反应。部分图片失败会提示原因，其余内容继续恢复，旧消息保留备用名称。
- 移除反应会释放原生附件；后续重新添加与移除通过同一队列串行，避免迟到删除误删新文件。浏览器环境保存一份 data URL。60 张上限按每张 30KiB 约 1.76MiB，不含元数据和导出封装。
- 小管家只处理新存档，不补写历史存档。请求失败保留原默认名称；不阻塞新对话。手动改名、删除目标、配置变化或作用域重载后，旧请求不能写回。普通切换到新对话不会取消仍有效的存档命名。
- 两个 AC 功能只使用明确选择的模型档，不自动使用女仆模型。记录任务状态、耗时及服务商实际返回的 token；缺少用量时明确显示未返回。
- 评分定义为 `0=无需修改、1=强烈建议修改`，默认关注阈值 `0.6`。缺段、重复 ID、越界分数均拒绝作为有效结果。它是通用模型评分预览，尚不是经过校准的 qev 专用适配器。
